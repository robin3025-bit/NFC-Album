# NFC-Album V0.2

## 로컬 시연

이 저장소에서 `node serve.mjs`를 실행하고 `http://127.0.0.1:8765/`를 엽니다. Google 계정을 연결하기 전에도 선택한 사진과 음악을 미리보기에서 재생할 수 있습니다.

## 디자인 테마 추가

`backgrounds/`에 이미지를 넣고 `themes.json`의 `themes` 배열에 테마 항목을 추가합니다. 같은 `categoryId`를 사용하면 기존 카테고리에 등록되며, JSON의 항목 순서대로 대표 테마와 캐러셀 순서가 정해집니다. 저장된 앨범이 같은 테마를 찾을 수 있도록 기존 `id`를 유지합니다.

## Google Drive 연동

- V0.1과 동일한 고정 OAuth 웹 클라이언트, GIS 토큰 모델, `drive.file` 권한, Drive 폴더와 멀티파트 업로드, 앨범 JSON 및 `?album=…&rk=…` URL을 사용합니다. OAuth 테스트 사용자와 허용 출처는 기존 Google Cloud 설정에서 확인합니다.
- API 키를 비워 둔 상태에서는 V0.1과 같이 감상 화면에서 API 키를 직접 입력합니다. 키 입력 없는 시연에는 GitHub Pages 출처와 Drive API 사용으로 제한한 공용 브라우저 키를 `config.js`에 설정합니다. 클라이언트 시크릿과 토큰은 설정 파일에 넣지 않습니다.
- 저장할 때 공유에 동의하면, 선택한 미디어와 앨범 JSON만 링크 읽기로 공유합니다. 앨범 폴더와 다른 개인 파일은 이 공유에 포함되지 않습니다. 링크가 전달되면 제3자도 콘텐츠를 열 수 있습니다.
- 기존 앨범을 저장하면 JSON을 제자리에서 갱신합니다. V0.1 앨범은 V0.1 감상 코드에서도 읽을 수 있도록 기존 형식을 유지합니다. 기존 영상은 감상과 편집 저장 시 보존되며 새 영상 추가는 지원하지 않습니다.
- 토큰이 만료되면 같은 계정을 연결해 다시 저장합니다. 실패할 때 이미 업로드하거나 공유한 파일과 앨범에서 제거한 파일은 Drive에 남을 수 있습니다. 각 파일의 공유 해제는 Drive에서 관리합니다.
- 로컬 미리보기에서 만들어진 링크는 로컬 서버를 가리킵니다. NFC에는 승인 후 확정된 GitHub Pages 감상 링크를 기록합니다.

## 검수 범위

- 브라우저 비교는 V0.1 원본과 V0.2를 같은 모의 Google API에 연결해 수행했습니다. 실제 테스트 계정의 OAuth, 개인 Drive 분리, 공개 공유 재생, 리소스 키가 필요한 기존 링크는 승인된 테스트 출처에서 별도로 검수합니다.
- Android와 iOS 실기기에서 NFC 접속, 화면 꺼짐 및 백그라운드 재생, 다음 곡 자동 재생, 잠금화면 제어를 별도로 검수합니다.
